# OfficeLedger 功能盤點

本文整理 OfficeLedger 目前已實作的產品功能。內容以現有程式與資料模型為準，作為後續產品討論、需求拆解與文件補齊的基礎。

## 產品定位

OfficeLedger 是辦公室與小型團隊使用的代墊款追蹤工具。它解決午餐、Uber Eats、臨時採買、聚餐活動等情境中，實際付款總額與每個人原始消費金額不一致時的分攤與追款問題。

核心使用者是團隊中先代墊款項的人。產品讓代墊人能建立可追蹤的交易，知道每個人應付多少、誰尚未還款、哪些款項已結清；其他參與者也能看到自己欠誰多少。

## 核心帳務總覽

首頁提供登入使用者的帳務概況：

- 顯示「我欠他人」與「他人欠我」的總額。
- 依同事彙總雙方往來狀態。
- 顯示每位同事的「他欠我」、「我欠他」、「我墊給他」、「他預付給我」。
- 顯示我作為付款人的交易，以及每筆交易的總金額、別人應還、尚未收回金額。
- 依同事彙總我代墊待還款的款項。
- 顯示最近帳務變動，包含交易欠款、預付款、還款、沖銷等紀錄。

## 一般代墊交易

使用者可以建立一筆正式代墊交易：

- 輸入交易標題。
- 選擇付款人。
- 輸入實付總額。
- 新增多位參與者。
- 為每位參與者輸入原始金額。
- 原始金額支援加總算式，例如 `250` 或 `50+20+15`。
- 建立前會先顯示分攤預覽，確認後才寫入正式交易。

分攤邏輯會以實付總額為錨點，依每位參與者的原始金額比例計算應付金額。系統以整數元為最小分配單位，先取整，再依小數餘數補差額，確保所有分攤金額加總等於實付總額。

## 交易詳情與銷帳

交易詳情頁提供每筆交易的分攤結果：

- 顯示付款人與實付總額。
- 顯示每位參與者的原始金額與分攤金額。
- 付款人不需要銷帳。
- 付款人可以對尚未結清的參與者逐筆銷帳。
- 若該參與者已有預付款或部分還款，頁面會顯示已沖抵或已還款金額。
- 參與者若已結清，會顯示已結清狀態。

## 活動記帳

活動記帳用於聚餐、團體點餐或需要多人共同輸入品項的情境。活動在結算前是草稿，結算後會轉成正式交易。

活動列表提供：

- 尚未結算的進行中活動。
- 已結算活動。
- 每個活動的付款人、目前總額、品項數與參與者數。
- 可從活動頁複製活動連結，方便分享給其他成員加入填寫。

建立活動時可設定：

- 活動名稱。
- 統一付款人。

活動詳情支援：

- 修改活動名稱。
- 修改統一付款人。
- 開啟或關閉服務費。
- 設定服務費比例。
- 自動儲存活動設定。
- 新增、修改、刪除品項。
- 每個品項可指定一位或多位分攤對象。
- 顯示品項記錄者。
- 即時計算小計、服務費、總額與每人應付金額。
- 付款人可刪除尚未結算的活動。
- 付款人可將活動結算成正式交易。

活動結算後會鎖定內容，並提供正式交易連結供後續銷帳。

## 品項與服務費分攤

活動品項分攤規則：

- 每個品項必須有品名、正整數元金額與至少一位分攤對象。
- 單人品項由該使用者全額負擔。
- 多人品項會平均拆分給所選分攤對象。
- 若品項金額無法平均整除，系統會以整數元分配，並依穩定排序補足剩餘金額。

服務費分攤規則：

- 服務費可關閉。
- 開啟時，依活動小計與服務費比例計算服務費。
- 服務費以整數元計算。
- 每位使用者的服務費依其品項小計比例分攤。
- 分攤後每人應付金額等於個人品項小計加上個人服務費。

## 同事往來帳

同事往來頁呈現目前使用者與特定同事之間的完整帳務關係：

- 顯示「我欠他」、「他欠我」、「我在他那邊的預付餘額」、「他在我這的預付餘額」。
- 顯示實際關係，將消費欠款與預付款影響合併後呈現最終方向。
- 顯示對方欠我的每筆尚未收回款項，並可逐筆標記已還款。
- 顯示我欠對方的每筆尚未還清款項，供檢視。
- 顯示待我確認的預付款或返還請求。
- 支援請對方返還預付款。
- 支援直接記錄對方已返還預付款。
- 顯示雙方完整往來紀錄。
- 銷帳紀錄若按錯，可透過沖銷還原欠款狀態。

## 預付款

預付款功能處理「先給一筆錢，之後用來抵扣消費」的情境。

使用者可以建立預付款紀錄：

- 我是預付方：送出後需要對方確認，確認後才正式入帳。
- 我是接收方：代替對方記錄預付給我的款項，立即入帳。
- 預付款對象不可為自己。
- 金額必須為正整數元。

當建立消費欠款時，系統會先檢查債務人對付款人的可用預付款。若有可用預付款，會先自動沖抵消費欠款，再將剩餘金額記為待還款。

預付款也支援返還：

- 可請對方返還預付款。
- 對方確認後才正式入帳。
- 若對方已實際返還，也可直接記錄返還。
- 返還金額不可超過可返還的預付餘額。

## 還款與沖銷

還款功能用於減少消費欠款：

- 可選擇還款對象。
- 系統會查詢目前對該同事的消費欠款上限。
- 還款金額不可超過目前消費欠款。
- 還款成功後會寫入付款紀錄並更新總覽。

銷帳功能也可在交易詳情或同事往來頁操作：

- 交易詳情可針對某一筆交易參與者銷帳。
- 同事往來頁可針對某一筆待收回款項銷帳。
- 銷帳紀錄保留在往來紀錄中。
- 手動銷帳可沖銷，沖銷後欠款會恢復為未結清狀態。

## 同事與帳號管理

OfficeLedger 目前支援基本帳號功能：

- 使用者註冊。
- 使用者登入。
- 使用者登出。
- 更換密碼。
- Session 管理。

同事管理功能包含：

- 查看所有人員。
- 新增同事帳號。
- 新增同事時可輸入顯示名稱、Email 與初始密碼。
- Email 可留空，系統會產生占位登入 Email。
- 新增完成後會顯示登入 Email，初始密碼不會再次顯示。
- 同事清單會用於交易、活動、預付款與還款的選人流程。

## 行動裝置與安裝體驗

目前 UI 已針對桌面與行動裝置提供不同呈現：

- 桌面使用頂部導覽。
- 行動裝置使用底部導覽。
- 多數列表在桌面顯示表格，在行動裝置顯示卡片。
- 支援 light 與 dark theme 切換。
- 提供 PWA manifest，可安裝到手機主畫面。
- 提供離線頁；離線時 App shell 與基礎導覽仍可開啟，但帳務資料需要連線後才能同步。

## 目前資料模型

主要資料模型包含：

- `User`：使用者與同事帳號。
- `Session`：登入 Session。
- `Transaction`：正式代墊交易。
- `TransactionParticipant`：交易參與者的原始金額與分攤金額。
- `DiningEvent`：活動草稿與已結算活動。
- `DiningEventItem`：活動品項、金額、分攤對象與記錄者。
- `PaymentLog`：所有帳務變動紀錄。
- `PrepaymentRequest`：預付款與預付款返還的確認請求。

`PaymentLog` 目前支援的類型：

- `EXPENSE_DEBT`：消費欠款。
- `EXPENSE_PREPAY_APPLY`：用預付款沖抵消費欠款。
- `PREPAYMENT`：預付款入帳。
- `PREPAYMENT_REFUND`：預付款返還。
- `SETTLEMENT`：還款或銷帳。
- `SETTLEMENT_REVERSAL`：銷帳沖銷。
- `ADJUSTMENT`：調整紀錄保留類型。

## 目前明確邊界

目前產品只作為帳務紀錄與追蹤工具，不處理金流本身：

- 不包含第三方支付流程。
- 不會自動轉帳。
- 不處理信用卡、銀行、電子支付串接。
- 不保證外部平台明細自動匯入。
- 所有還款、預付與返還都以使用者手動確認或記錄為準。
